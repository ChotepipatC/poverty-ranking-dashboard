# Dashboard อันดับจังหวัดที่มีสัดส่วนคนจนสูงสุด พ.ศ. 2543–2568

แดชบอร์ดแบบไฟล์เดียว (`index.html`) แสดงการเปลี่ยนแปลงอันดับสัดส่วนคนจนรายจังหวัดและรายภาค
พร้อมจำนวนคนจน เส้นความยากจน ค่าทั้งประเทศ และ Dynamic bar chart

- มุมมองรายจังหวัด / รายภาค
- เน้นได้สูงสุด 4 จังหวัด, ตัวกรองภาค, ช่วงเวลา (เริ่มต้น 2549–2568)
- รองรับคอมพิวเตอร์ แท็บเลต และมือถือ

## ที่มาของข้อมูล
ตารางที่ 1.1–1.6 จากการสำรวจภาวะเศรษฐกิจและสังคมของครัวเรือน สำนักงานสถิติแห่งชาติ
ประมวลผลโดยกองพัฒนาข้อมูลและตัวชี้วัดสังคม สศช. (ไฟล์ปรับปรุงล่าสุด 9 ก.ค. 2569)

## เปิดใช้งาน
เปิด `index.html` ในเบราว์เซอร์ได้ทันที หรือเปิด GitHub Pages
(Settings → Pages → Deploy from a branch → `main` / root)
